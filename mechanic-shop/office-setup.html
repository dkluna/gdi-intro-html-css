Repair shop · pricing assistant

Office Computer Setup

Install the pricing assistant on the shop's main computer, about 45 minutes. When you're done, the pricer can hand it a photo of the inspection form and get back a checked parts list from Worldpac.

0 of 9 steps done

Before you start

  • A Windows 10 or 11 PC (64-bit) or a Mac (macOS 11 or newer). Use the computer the pricer already uses for Worldpac and Mitchell 1. Windows on ARM isn't supported.
  • Google Chrome installed. Claude in Chrome doesn't work in Edge or other browsers.
  • The shop's Worldpac login working in Chrome.
  • A paid Claude plan (Pro, Max or Team). Set it up under a shop email the owner controls, not a personal account.
  • The skill file shop-pricing-assistant.zip, downloaded onto that computer.
  • The owner or ops manager nearby for step 7, since they decide what the assistant may do on its own.

Steps

  1. Set up the Claude account

    • Go to claude.ai and sign up with the shop email.
    • Choose a paid plan. Pro is the minimum. Team is best if the owner, ops manager and pricer will all use it, because a skill can be shared across the team.
    Claude in Chrome on Pro may offer fewer model choices than Max or Team. Start on Pro if you like, and upgrade if the parts picks aren't accurate enough.

  2. Install the Claude desktop app

    • Download it from claude.ai/download and install it.
    • Open it and sign in with the shop account.
    • If it offers a readiness check for Cowork, run it.
    Check: the app shows a mode selector with a Cowork tab.

  3. Turn on code execution

    Skills need this setting on.

    • Pro or Max: Settings → Capabilities → turn on Code execution and file creation.
    • Team: the account owner opens Organization settings → Plugins & skills and makes sure both Code execution and file creation and Skills are on. They're usually on by default.

  4. Upload the pricing skill

    1. Go to Customize → Skills.
    2. Click +, then + Create skill, then Upload a skill.
    3. Choose shop-pricing-assistant.zip. Don't unzip it first.
    4. Make sure the skill is toggled on.
    Check: shop-pricing-assistant appears in the skills list.

  5. Install Claude in Chrome

    1. Open Chrome and search the Chrome Web Store for Claude (published by Anthropic).
    2. Click Add to Chrome.
    3. Sign in with the same shop account.
    4. Pin it: click the puzzle-piece icon, then the pin next to Claude.
    5. Approve the permissions it asks for. They're what let Claude read and click pages for you.

  6. Connect Chrome to the desktop app

    1. In the desktop app: Settings → Connectors.
    2. Find Claude in Chrome, click Configure, and turn it on.
    The Chrome connector starts off in every new conversation. When you start pricing a car, turn it on for that conversation (it's in the conversation's tools or connectors menu).

  7. Set the safety settings

    Do this with the owner or ops manager.

    • Make it ask first. The Chrome side panel starts in Automatically approve. Switch it to the mode where Claude asks before acting. It keeps that setting afterwards.
    • Limit the websites. Only allow the sites it needs: Worldpac, and the free VIN decoder at vpic.nhtsa.dot.gov. On Team, the admin can set an allowlist so it can't go anywhere else.
    • Log in to Worldpac yourself, in Chrome as usual. Never type a password into the Claude chat.
    • Keep Mitchell 1 open and handled by the pricer as today. The assistant doesn't touch it.
    Claude in Chrome acts on real websites, and Anthropic says it still carries risk. The skill tells it never to order, add to cart or export, but "ask before acting" is the safety net.

  8. Run a practice job

    1. Pick a car that has already been priced, ideally a brake job.
    2. Take phone photos of the tech's inspection form and the Mitchell 1 worksheet, and get them onto the computer.
    3. In the desktop app, open Cowork, start a new task, turn on Claude in Chrome for it, attach the photos, and paste this:
    Use the shop pricing assistant skill. Price out this repair order from the attached photos (inspection form and Mitchell worksheet). Look up the parts in Worldpac in Chrome, where I'm already logged in. Do not add anything to a cart, order, or export. Just give me the parts list in the playbook's format, with flags at the top and any questions for the tech.
    1. Compare its list with what was actually ordered for that car: same parts, same quantities, same prices?
    Check: the list matches, or the differences make sense and you've noted them.

  9. Start using it on new cars

    • Pricer: photograph the form, run the prompt above, answer or forward any tech questions, then select those parts in Worldpac and use the usual Export to Mitchell 1.
    • Owner or ops manager: review every final quote before the customer call, starting with the flags at the top.
    • Keep the Claude app open while it works. Closing it ends the task.
    • When it gets something wrong, write it down. Those notes are how the playbook gets better.

If something goes wrong

The skill won't uploadUpload the ZIP as-is, without unzipping or renaming it. The folder inside must stay named shop-pricing-assistant. Check that code execution is on (step 3).
No "Upload a skill" optionOn Team, the owner may have turned off member skills. Turn them on in Organization settings.
Claude can't see ChromeTurn on the Claude in Chrome connector for this conversation (step 6), and check that Chrome is open and signed in to the same account.
Worldpac asks for a loginLog in yourself in Chrome, then ask Claude to continue.
Claude can't open a siteThe site isn't on the allowlist. Only add it if the owner agrees.
The task stoppedThe Claude app was closed or the computer went to sleep. Reopen it and start the task again.
It doesn't seem to follow the playbookStart the prompt with "Use the shop pricing assistant skill," and check that the skill is toggled on in Customize → Skills.
Menu names come from Anthropic's help center and may shift slightly as the apps update. Help center: Claude in Chrome · Skills · Cowork
